# Auto Fix Demo Project

This demo ZIP is intentionally vulnerable.

It contains dependency manifest files that can be used for the ZCS SBOM flow:

- `package.json`
- `package-lock.json`
- `pom.xml`

Expected vulnerable examples:

- `lodash@4.17.19`
- `minimist@0.0.8`
- `log4j-core@2.14.1`
- `jackson-databind@2.12.0`
- `spring-core@5.3.0`
